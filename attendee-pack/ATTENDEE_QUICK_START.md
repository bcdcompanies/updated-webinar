# Attendee Quick Start

Use this guide if you are joining a webinar session.

## 1. No Installation Required

You do not need to install software.

You only need:

- A modern browser (Chrome, Edge, Safari, or Firefox)
- A stable internet connection
- Your unique join link from the host

## 2. Join Steps

1. Open your unique join link.
2. Enter your display name.
3. Select Join webinar.
4. If prompted, allow microphone/camera access only if asked by the host.

## 3. During the Session

- You join as view-only by default.
- Host can promote you to speaker when needed.
- If disconnected, reopen the same join link to rejoin.

## 4. Best Experience Tips

- Use wired or stable Wi-Fi connection.
- Close heavy background apps/tabs.
- Use headphones to avoid echo.
- Keep browser updated.

## 5. If You Have Trouble Joining

1. Refresh the page once.
2. Reopen the link from the invite.
3. Try another browser.
4. Ask host to resend your join link.
