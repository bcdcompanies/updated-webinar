# Host Event Runbook

Use this runbook to operate a live webinar with real attendees.

## 1. Pre-Event Checklist (15-30 minutes before)

1. Confirm app URL is publicly reachable over HTTPS.
2. Confirm LiveKit URL uses wss:// in production.
3. Verify host key is available to host operators.
4. Create webinar title, description, and schedule.
5. Generate or send attendee invite links.
6. Start session 5 to 10 minutes early.
7. Test host mic/camera and screen share.

## 2. Session Start

1. Open webinar details.
2. Select Start session.
3. Select Enter room.
4. Confirm host video/audio state.
5. Watch attendee count as people join.

## 3. During Event

1. Use Manage attendees to monitor participants.
2. Promote attendee to speaker only when needed.
3. Return attendee to view-only after speaking.
4. Remove disruptive attendees if required.
5. Keep one backup host device signed in.

## 4. Session End

1. Return to webinar detail page.
2. Select End session.
3. Confirm status changes to ended.
4. Capture notes: issues, dropouts, quality concerns.

## 5. Recovery Actions

If attendees cannot join:

1. Verify join link is correct for each attendee.
2. Verify app and LiveKit service health.
3. Share fresh link from webinar Invite section.
4. Ask attendee to switch browser/network.
